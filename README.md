# パパジム

器具なしの筋トレとストレッチを、毎日ゼロにせず続けるための個人用アプリです（iPhoneのホーム画面に追加して使うWebアプリ）。

- **最低ライン**：1種目だけで「やった日」。**目標ライン**：約10分のメニュー（準備1＋筋トレ3＋ストレッチ3）
- 曜日ごとのテーマ（月：下半身＋プランク／火：押す／水：体幹／木：片脚・下半身／金：引く／土：全身（スクワット・腕立て・プランク）／日：ストレッチ）。全69種目。スクワット・腕立て伏せ・プランクは週3日以上、立って前屈と股関節のストレッチはほぼ毎日入り、残りは週ごとに入れ替わる。根拠：厚労省「身体活動・運動ガイド2023」、ACSM、NSCA、日本整形外科学会ロコトレ、McGillのビッグ3
- 段階メニュー：量が2週ごとに上がり（85→100→120→140→160%）、4週に1回は回復週（その段階の75%）。きつい日が続くと据え置き、7日以上あくと1段階戻る
- 各種目に、詳しいやり方・効く場所・効能を表示
- 連続記録・お休みチケット（毎月2枚、最大3枚）・カード収集・レベル
- 育てるキャラ「ムキたま」（SVG）：やった日の数で たまご→ちびムキ→こムキ→ムキたま→マスター（3/10/30/100日）。直近30日の筋トレ／ストレッチの割合で型が変わり、げんき（ハート）はさぼると減るだけで、育ちは戻らない。着せかえ・ずかん・4つのステータスつき。保存するのは名前・着せかえ・ずかんだけで、あとは記録から計算
- 家族の要素（写真つき応援、20歳のときの年齢、家族とのごほうび）。家族側の操作は一切不要
- 月1回の体力チェックと推移グラフ
- 「あゆみ」：累計回数・1年カレンダー・週ごとの回数・成長の記録・ランキングとバッジ・ふりかえり年表
- 全69種目の動きがわかるGIFアニメ（`python3 scripts/gen-gifs.py` で再生成。要Pillow）
- 目標ラインの種目の間に30秒の休憩と、健康の豆知識クイズ
- データは端末内（IndexedDB）のみ。設定からバックアップを書き出せます

## 開発

```sh
npm install
npm run dev     # http://localhost:5173/papa-gym/
npm test        # ロジックのテスト
npm run build
```

## 公開（GitHub Pages）

リポジトリの Settings → Pages → Source を **GitHub Actions** にすると、`main` への push で自動公開されます。
公開後、iPhoneのSafariで `https://<ユーザー名>.github.io/papa-gym/` を開き、共有ボタンから「ホーム画面に追加」します。
